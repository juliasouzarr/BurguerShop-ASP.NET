# 🍔 Burger Shop  
### ASP.NET Web Application

This project is a simple web application developed using C# and ASP.NET to simulate a handcrafted burger shop interface.

It focuses on structuring web pages and navigation using ASP.NET features.

---

## 📌 Purpose

The main goal of this project is to practice web development with ASP.NET, including page structure, navigation, and layout organization.

---

## 🧩 Features

- Main menu page (Master Page)  
- Individual detail pages for each menu item  
- Structured navigation between pages  
- Basic user interface for product visualization  

---

## ⚙️ Functionality

The application uses a **Master Page** to define the main layout and navigation structure, ensuring consistency across the system.

Each product is presented on a dedicated **Detail Page**, allowing a clear and organized display of information.

---

## 🛠️ Tech Stack

- **Backend:** C#  
- **Framework:** ASP.NET  
- **Frontend:** HTML, CSS  
- **Architecture:** Web Forms (Master Page + Content Pages)  

---


## 🎯 Learning Outcomes

- Understanding of ASP.NET page lifecycle  
- Use of Master Pages for layout standardization  
- Navigation between multiple pages  
- Structuring simple web applications
